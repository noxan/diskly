# Security Policy

## Supported Versions

Only the [latest release](https://github.com/noxan/diskly/releases/latest) is supported.

## Reporting a Vulnerability

Please report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/noxan/diskly/security/advisories/new).

Expect an initial response within 7 days. Please don't open a public issue for
security reports.
